Kanal-Uebersicht

Kanal-Uebersicht ist ein privates Werkzeug, das nur auf dem eigenen Rechner des Betreibers läuft. Es zeigt die Statistiken der eigenen YouTube-Kanäle des Betreibers auf einer Seite an und wird nicht an andere Personen verteilt.

Datenschutzerklärung

Welche Daten

Mit Zustimmung des Kontoinhabers liest die Anwendung über die YouTube Data API, die YouTube Analytics API und die YouTube Reporting API die Kanal- und Videodaten sowie die Statistiken der eigenen Kanäle. Die Zugriffe sind nur lesend. Die Anwendung ändert, veröffentlicht oder löscht nichts.

Wo die Daten bleiben

Alle Daten und Anmeldeschlüssel werden ausschließlich lokal auf dem Rechner des Betreibers gespeichert. Sie werden nicht an Dritte weitergegeben, nicht verkauft und nicht für Werbung genutzt.

Löschen

Der Zugriff lässt sich jederzeit unter myaccount.google.com/permissions widerrufen. Die lokal gespeicherten Daten löscht der Betreiber dann selbst.

Die Anwendung nutzt YouTube API Services. Es gelten die YouTube-Nutzungsbedingungen und die Google-Datenschutzerklärung.

Privacy Policy (English)

Kanal-Uebersicht is a private tool that runs only on its owner's own computer and displays statistics of the owner's own YouTube channels. With the account holder's consent it reads channel, video and analytics data through the YouTube Data API, YouTube Analytics API and YouTube Reporting API, read-only. All data and credentials are stored locally on the owner's computer only. They are never shared, sold or used for advertising. Access can be revoked at any time at myaccount.google.com/permissions. This app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
